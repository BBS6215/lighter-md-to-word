# 架构与行为约定

首版为共享 TypeScript 核心、单 HTML 和 CLI。不引入账号、数据库、转换服务器、MCP、实时同步或正文日志。

## 数据流

`Markdown → remark AST → DocumentModel → 浏览器预览 / docx Document → DOCX`

DocumentModel 包含已处理编号的标题、段落、表格、内联格式、列表上下文、统计及警告。HTML 和 CLI 均通过 `parseDocument` 和 `generateWord`，不维护两套排版实现。预览近似真实页面，Word 排版器负责最终分页。

`profiles.ts` 是配置 schema 和出厂值的权威来源。配置集合为 `{ schemaVersion: 1, profiles: [{ id, name, settings }] }`，1–3 套，必须保留 ID 为 `default`、名称为“默认配置”的配置。字体、字号、对齐、缩进为各文字样式独立参数；行距和段间距为全局参数；页码另设字号、位置、格式及开关。

配置校验拒绝未知字段、非法数值、重名、缺失默认配置和不支持的版本，避免意外把正文等额外字段导出到配置文件。导入整体替换，不做猜测式合并。

## 浏览器

源码正文、文件名、清除快照、字体检测结果仅存在内存。正文不写入 localStorage、sessionStorage、IndexedDB 或日志。撤销清除快照最多保留 6 秒，输入新内容后立即失效。

localStorage 只保存配置集合和页面最近选择。尝试写入后回读核验，失败时显示提示并保留本次可用设置；下载 JSON 供可靠备份。初始化读取失败时临时使用出厂值，不在初始化阶段覆盖原始存储。

静态脚本及 CSS 全部内联，CSP 禁止联网、外部脚本、远程资源及原始 HTML 执行。预览中的文字和属性转义，链接只允许 http、https、mailto，点击由用户决定。图片不加载。大段粘贴使用 textarea 的直接范围替换，避免 Chromium 原生长文本插入的性能问题；普通编辑保持原生行为。

下载按钮只声称“已生成并发起下载”，不把浏览器事件当作用户最终保存成功。工具不上传输入，不提供浏览器存储与 CLI 的隐式同步。

## CLI

CLI 打包为 Node.js ESM，由 Windows `.cmd` 包装器通过自身目录调用。默认配置定位为工具根目录的 `.local/profiles.json`，不依赖 cwd；显式相对输入、输出和 `--config` 路径按调用目录解析。

转换每次读取配置，选择 `default` 或明确指定的 ID/唯一名称，固定本次模型与设置，再生成文件。只在隐式默认配置缺失时使用内置配置。文件损坏、未知配置、读写失败和无效 UTF-8 返回非零退出码。

配置导入：读取并校验全部内容 → 同目录独立临时文件（wx）→ 写入、sync、关闭 → rename 替换 → 回读并比较 → 输出成功结果。任何替换失败均不通过删除旧目标来绕过。只清理本次创建的临时文件。

Word 输出以 wx 独占创建，重名递增后缀；失败时只删除本次未完成的输出，不覆盖已有文件。CLI 不修改源 MD，不生成正文副本，不输出正文。

## 公开交付

`md2word.html` 是随源码提交的生成产物，`pnpm build` 可重建。`build/`、依赖、个人配置、测试输出、环境文件和真实成品均不提交。所有示例和测试使用合成内容。

必要检查为类型检查、核心/文件操作回归、单文件构建、真实 file:// 浏览器下载、跨目录 CLI 调用及 Word 渲染。涉及真实排版变化时应重新渲染查看。README、CLI 帮助、配置格式和实际行为保持一致。
