# 架构与行为约定

首版为共享 TypeScript 核心、单 HTML 和 CLI。不引入账号、数据库、转换服务器、MCP、实时同步或正文日志。

当前版本为 1.1.0。CLI 和 HTML 的版本标识读取 package.json，配置 schemaVersion 保持 1，Word 输出规则和 CLI 参数保持兼容。

## 数据流

`Markdown → remark AST → DocumentModel → 浏览器预览 / docx Document → DOCX`

DocumentModel 包含已处理编号的标题、段落、表格、内联格式、列表上下文、统计及警告。HTML 和 CLI 均通过 `parseDocument` 和 `generateWord`，不维护两套排版实现。预览近似真实页面，Word 排版器负责最终分页。

引用定义以显式栈按全文顺序收集，首个定义生效；相对/不支持协议的链接保留为普通文字和地址。大标题重置下级计数，逐位中文数字和带单位数字分别解析；零编号与未开始计数分开处理。独立 br 生成空段落，分隔线按 AST 节点删除并提示数量，不删除普通减号或表格语法。

每次父标题处理均先重置下级计数，再处理手写编号及异常分支，超限编号的提前返回不能绕过重置。

共同的 XML 1.0 字符检查保护正文、解码后的文字片段、链接目标、标题和配置字体。发现禁止字符即失败，不静默清理。Word 生成入口再检查模型文本，避免绕过 Markdown 解析的调用者生成非法 XML。错误只含字段、编码与位置，不带整篇正文。

`profiles.ts` 是配置 schema 和出厂值的权威来源。配置集合为 `{ schemaVersion: 1, profiles: [{ id, name, settings }] }`，1–3 套，必须保留 ID 为 `default`、名称为“默认配置”的配置。字体、字号、对齐、缩进为各文字样式独立参数；行距和段间距为全局参数；页码另设字号、位置、格式及开关。

配置校验拒绝未知字段、非法数值、重名、缺失默认配置和不支持的版本，避免意外把正文等额外字段导出到配置文件。导入整体替换，不做猜测式合并。

## 浏览器

源码正文、文件名、清除快照、字体检测结果仅存在内存。正文不写入 localStorage、sessionStorage、IndexedDB 或日志。撤销清除快照最多保留 6 秒，输入新内容后立即失效。

localStorage 保存配置集合、页面最近选择，以及独立键 `md2word.sync-scroll.v1` 下的同步开关布尔值。正文、文件名、光标、位置映射和滚动历史不持久化，UI 偏好不进入 schemaVersion 1 的配置 JSON。配置尝试写入后回读核验，失败时显示提示并保留本次可用设置；下载 JSON 供可靠备份。初始化读取失败时临时使用出厂值，不在初始化阶段覆盖原始存储。

### 同段滚动与界面

共享解析模型中的可选 `source: { start, end }` 为传入 parseDocument 字符串的 UTF-16 偏移，补偿解析前去掉的开头 BOM；Word 生成器不消费这些字段。浏览器只使用 editor.value 的同一份快照，其换行已由 textarea API 统一为 LF。预览元素只输出数值来源属性，不执行源 HTML。

`ScrollSync` 使用不可见、等样式的文本镜像复制真实可用宽度、字体、行高、Tab、内边距和换行规则，用 DOM Range 测量块首尾。重复来源合组，跳过无来源的辅助段落，构成单调的原文/预览定位表；块内及间隙插值，顶底单独处理。不把全文滚动百分比作为主映射。

测量按帧分批，文稿或几何变化使旧任务失效；滚动只复用数值缓存并按帧同步。测量结束移除镜像，仅保留数值几何。关闭同步、单栏、清空和解析失败时释放缓存，异常只暂停同步，不影响导出。设置或宽度变化尽量保留阅读来源位置；同步不调用 focus 或 setSelectionRange。用户输入接管主动侧，程序滚动的目标值用于抑制反向循环。

桌面双栏断点为 901px，单栏停用联动；同步开关偏好单独保存。A4 预览仅调整显示缩放，不修改 Word 样式；稳定滚动条占位避免临界高度反复缩放。图标为内嵌 SVG，仍为单 HTML。微过渡尊重减少动态效果设置。

消息使用递增序号；成功消息在 4.5 秒后仅清除自身，错误不会被旧计时器或较早在途导出的结果覆盖。读取中提示持续到结果，生成按钮延迟 200ms 显示忙碌文字，但立即禁止重复导出。拖入反馈只改变工作区边界，不改变原有导入任务序号规则。

正文修改递增文稿版本并使旧模型失效；解析明确返回有效模型或失败。失败时旧模型和预览清空，当前正文保留；导出必须取得当前正文的解析结果，再在第一个 await 前固定模型、配置、文件名和文稿版本。后续修改不改变在途导出，完成消息不能覆盖新正文的解析错误。

Markdown 选择与拖放共用导入入口，进入时先递增读取序号，再校验扩展名。后选非法文件不改当前稿，但旧读取的成功或失败都不能再修改正文、文件名和提示。

手动文件名、导入来源主名与 DOM 显示值分别管理；清除和撤销同时处理这些内存元数据。关闭设置统一丢弃无效草稿、恢复最近合法值；不回读持久化配置来撤销仅在本次内存中合法生效的设置。

配置文件异步读取使用单独的任务序号。新文件选择、配置编辑等新操作使旧读取失效；较早任务的成功与失败都不改变新状态。后选文件无效时保留原合法集合，不回退应用旧任务结果。

静态脚本及 CSS 全部内联，CSP 禁止联网、外部脚本、远程资源及原始 HTML 执行。预览中的文字和属性转义，链接只允许 http、https、mailto，点击由用户决定。图片不加载。大段粘贴使用 textarea 的直接范围替换，避免 Chromium 原生长文本插入的性能问题；普通编辑保持原生行为。

下载按钮只声称“已生成并发起下载”，不把浏览器事件当作用户最终保存成功。工具不上传输入，不提供浏览器存储与 CLI 的隐式同步。

## CLI

CLI 打包为 Node.js ESM，公开成品为 `cli/md2word.mjs`，Windows `.cmd` 包装器通过自身目录调用该成品；`build/cli.js` 保留供开发与既有本机 Skill 使用。两者由同一次构建生成且内容相同。分发 CLI 只依赖 Node.js 内置模块，下载 CLI 便携 ZIP 后无须安装开发依赖。默认配置定位为工具根目录的 `.local/profiles.json`，不依赖 cwd；显式相对输入、输出和 `--config` 路径按调用目录解析。

转换每次读取配置，选择 `default` 或明确指定的 ID/唯一名称，固定本次模型与设置，再生成文件。只在隐式默认配置缺失时使用内置配置。文件损坏、未知配置、读写失败和无效 UTF-8 返回非零退出码。

配置导入：读取并校验全部内容 → 同目录独立临时文件（wx）→ 写入、sync、关闭 → rename 替换 → 回读并比较 → 输出成功结果。任何替换失败均不通过删除旧目标来绕过。只清理本次创建的临时文件。

Word 输出以 wx 独占创建，重名递增后缀；失败时只删除本次未完成的输出，不覆盖已有文件。CLI 不修改源 MD，不生成正文副本，不输出正文。

## 公开交付

`md2word.html` 是随源码提交的生成产物，`pnpm build` 可重建。`cli/md2word.mjs` 同样随源码提交并由 CI 重建核对；`build/`、开发依赖、个人配置、测试输出、环境文件和真实文档成品均不提交。所有示例和测试使用合成内容。

必要检查为类型检查、核心/文件操作回归、单文件构建、真实 file:// 浏览器下载、跨目录 CLI 调用及 Word 渲染。涉及真实排版变化时应重新渲染查看。README、CLI 帮助、配置格式和实际行为保持一致。

执行 `pnpm check` 时先类型检查和构建，再运行包含真实 CLI 的核心集成测试与浏览器检查。回归需覆盖失败恢复、异步交错、生成包中所有 XML/关系文件的严格解析，不能仅验证正常点击路径。

产品显示名称为 Lighter · MD to Word；仓库与本机目录统一为 lighter-md-to-word，CLI 短命令、HTML 文件名及配置键保持兼容。README.md 与 README.en.md 分别提供中文和英文入口。字体与编号支持公文材料常用排法，但当前自定义默认值并非完整 GB/T 9704—2012 模板；不因宣传而修改既有配置或 Word 样式。

`downloads/lighter-md-to-word-cli.zip` 由同一构建生成，包含 CLI、Windows 包装器、双语快速说明及许可，不含 Node.js、开发依赖、个人配置和源材料。文本换行及 ZIP 文件时间固定以跨平台重建核对，CI 同时检查 JS 与 ZIP 成品。
