## 1.1.0 验收

日期：2026-11-13。基线 1.0.2（4df2495）。先在原界面完成同段同步原型，再更新蓝色界面、图标与反馈；不变更 Word 排版规则、CLI 参数或配置 schemaVersion 1。使用合成内容。

- `pnpm check`：类型检查、构建、43 项核心/CLI 测试和 29 项 Chrome 浏览器测试通过，共 72 项。保留原有 58 项，新增 5 项来源/Word 不变性测试及 9 项浏览器回归。
- 同段原型及最终布局均在 Chrome、Edge 检查。最终 Edge 额外执行全部 9 项新增浏览器测试。通过浏览器原生 `caretPositionFromPoint` 核对双向对应段落，包含 BOM、CRLF、中文/英文长串、emoji、Tab、自动换行、引用和嵌套列表；检查顶底、宽度变化、设置重建及焦点/光标不变。
- 超过 200 KiB 的定位表构建完成后，连续滚动不会再次调用镜像 Range 测量；旧测量被新稿打断后不能恢复旧稿，结束后无遗留镜像。人为令测量失败，仍可下载真实 Word，下一稿恢复同步。原有超 200 KiB 导入/粘贴与完整导出测试继续通过。
- 同步开关单独保存；单栏停用，回到双栏恢复偏好。配置 JSON 只有 schemaVersion/profiles，正文及同步偏好不混入；刷新清空正文。关闭同步可分别阅读，不强制拉动。
- 新增嵌套拖入反馈、旧成功计时器不能清除新错误、在途导出不能覆盖后续文件选择错误、当前成功提示可收起的直接断言。保留原有解析失败、导出快照、配置导入竞态及非法选择取消旧读取的回归。
- 离线检查内嵌 SVG 能解码为图标、A4 适应面板宽度、键盘可展开预览说明、减少动态效果设置生效，无 HTTP/HTTPS 请求。390px viewport 无页面横向溢出；桌面、设置弹窗和单栏页面以合成材料截图目检。viewport 检查不等于手机真机测试。
- 来源元数据有无两种模型生成的 document/styles/footer XML 一致；浏览器下载与共享引擎 XML 一致；包内 XML 和关系文件严格解析通过。
- 新 CLI 实际输出版本 1.1.0，中文含空格路径转换成功，重复输出递增名称，未知配置明确失败。合成示例（30 段）通过官方 OOXML 校验，LibreOffice 渲染为两页并逐页目检；WPS 12.1.0.29670 实际打开，无修复提示，显示两页。输入原稿与已有输出保护由 CLI 回归继续核对。
- 本机薄 Skill 通过系统 Skill Creator 元数据校验，Claude/Codex Junction 指向同一正式源，AgentHub 对应 L2 门禁通过。Codex app-server 的 skills/list 与 Claude 初始化控制响应均实际列出 md2word；这属于宿主发现验证，未发起模型生成或声称完成自然语言触发率评测。按 Skill 中的实际 CLI 入口完成成功/失败成品检查。
- 构建产物约 0.67 MB，无新增依赖或外部资源。正式交付前复建比较 HTML、CLI、许可证及示例配置哈希；公开提交只包含代码、说明、合成测试和生成 HTML，不包含个人 Skill 安装路径、配置、截图、会话或转换成品。
