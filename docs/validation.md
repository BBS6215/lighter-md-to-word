# 1.0.1 验证记录

日期：2026-11-12。使用公开仓库中的合成示例，不使用真实工作材料。字体需由使用者在本机安装，字体文件不随项目分发。

- Windows x64，Node.js 24.19.0，pnpm 10.28.1。
- 桌面 Chrome 157，Playwright 1.65.0。
- WPS Office 12.1.0.29670。
- LibreOffice 26.8.0.3，通过独立配置目录渲染，不修改用户已有文档。

## 已完成检查

- `pnpm typecheck`、构建及 `pnpm test`：35 项核心/CLI 测试通过。原有 13 项保留，补充编号、链接、换行、文件名、非法 XML 字符、模型入口防护、重复名称/ID 的直接断言，以及真实 CLI 的版本和失败不落盘验证。
- `pnpm test:browser`：16 项通过，保留原有 5 项，新增 11 项。真实 `file://` 下载 DOCX 并比较共享引擎的 document/styles/footer；覆盖解析失败清空旧稿、错误后恢复、异步内容/配置/名称快照、完成反馈不覆盖新错误、关闭/Escape 放弃无效草稿、配置读取交错、无效新文件及旧失败读取、手动修改使旧导入失效、无 H1 名称回退和所有 XML/关系文件的严格解析。
- 长文：浏览器导入及大段粘贴超过 200 KiB 的合成材料，实际下载的 Word 含末尾标记。保留完整导出，不以预览片段冒充全文。
- 响应式布局：390px 宽度无页面横向溢出；桌面内容与设置界面可操作。手机 viewport 检查不等于手机真机实测。
- CLI 输出：实际处理中文与含空格的路径，源 MD 不变，已有 Word 不覆盖；默认配置路径不随工作目录变化。
- DOCX：1.0.1 新生成基础样例（30 段）和边界样例（20 段）均通过官方 OOXML 校验；浏览器独立 DOMParser 严格解析生成包内所有 XML 和关系文件。非法字符覆盖 NUL、U+0001、U+000B、U+FFFE、U+FFFF、未配对代理项；合法中文、换行和 emoji 保留。
- 页面：基础样例渲染为两页，边界样例为一页，三页均逐页目检。WPS 实际打开 1.0.1 边界文档无修复提示，确认零起始任务、相对资料地址、独立换行、父级重置、逐位中文编号和数字页码。不同排版器的分页可能略有不同。
- 打包：单 HTML 内联全部必要脚本与样式，内嵌运行依赖许可证，单独分享时仍保留许可文本。原始 Markdown 不写入持久存储。
- 公开内容：排除个人配置、真实文档、转换输出及测试截图；扫描源码、文档和生成 HTML，未发现本机私有路径、真实材料正文或会话内容。

## 修复前证据与原记录更正

初版 1.0.0 的 18 项既有测试确实通过，但未覆盖本次边界，不能据此认为全部验收完成。最初新增的 19 项核心回归在旧版上为 17 项失败、2 项通过；三项定向浏览器回归也复现了导出文件名错配和旧配置覆盖新选择。修复后这些场景均通过。

初版记录曾将“配置重名”写为已覆盖，但没有直接触发重复配置名称/ID 的测试，本记录予以更正。1.0.1 已新增两种独立断言；实现本身原有的重名防护保留。

分隔线依用户确认继续去掉，并给出排版说明，不将恢复横线作为验收条件。配置 schemaVersion 保持 1，未升级依赖或更改 CLI 参数。
